# Pre-load set

Synthetic demonstration documents. Each file starts with "Synthetic demonstration document".

- Origin: exported unchanged from the `v1_corpus_db` corpus into `demo_data/corpus/` on 7 November 2026, then copied here.
- Why these five: the hero companies (Jade Logistics, Pacific Foods, Straits Chemicals), the SAR of Jade's director AHMAD BIN OSMAN, and Raffles Holdings for the treasury product.
- Use: set `C360_PRELOAD_DIR` to this folder. On first start with an empty library the app extracts and indexes them and builds the graph.
- Unlike `demo_data/corpus/`, this folder is tracked in Git.
