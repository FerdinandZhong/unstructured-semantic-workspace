# Data

The workspace ships two sample datasets: Financial Services and Manufacturing.
All shipped data is synthetic or carries a public licence.
Synthetic files say so inside the file.
Public files keep their attribution and scope `extraction_only`.

!!! note "Data leaves the process"
    Mistral receives the content of every processed file.
    Load only data you may send to that provider.

## Labels and scope

Every source carries a data label.

| Label | Meaning | Rules |
| --- | --- | --- |
| Synthetic | Written for this project | Labelled synthetic in the file |
| Public, Public sample | A public file under an open licence | Scope `extraction_only`: linked to definitions, never induced into concepts, never tied to an entity |

Each source is pinned by SHA-256 in `demo_data/extra_sources.json` and the workspace registry.

## Financial Services

### Structured data

The structured data is a mock-up banking workbook.
It is synthetic. It contains no real customer.

| Item | Value |
| --- | --- |
| Tables in the model | 11 snapshot tables |
| Period | Transactions for 4 to 6 November 2026 only |
| Form | CSV projections loaded read-only into a PostgreSQL schema `v2_facts_<dataset>` |
| Semantic model | `demo_data/finance/finance.ossie.yaml`, 143 definitions |

### FIBO definitions

The finance model attaches a secondary definition from the Financial Industry Business Ontology (FIBO) to five concepts:
customer, account, banking product, currency and relationship manager.
Each concept keeps its own definition from the source schema.
The FIBO text sits unchanged beside it, with the class IRI, label, definition, source file and licence note.

- Publisher: Enterprise Data Management Council.
- Repository: <https://github.com/edmcouncil/fibo>
- Licence: MIT.

### Documents

| Set | Count | Label |
| --- | --- | --- |
| Finance document pack (`FIN-001` to `FIN-012`) | 12 | Synthetic |
| Adverse-media articles and one suspicious-activity report about fictional companies | 5 | Synthetic |
| A Word review built from a public chart | 1 | Public, CC BY-SA 4.0 |

The finance pack is generated by a script with no network access.
Its documents name only customers, accounts, relationship managers and transactions that are rows of the workbook, with their exact keys and recorded values.
They also state commitments the workbook does not record.
The pack manifest holds planted truth from the generator. It is not an independent gold set.

The public document is built from a chart on Wikimedia Commons.
Its source page is `commons.wikimedia.org/wiki/File:<title>`.
Keep the attribution when showing it.

### Forms and the recorded call

The table-write feature was built with five cleaned PDFs (three printed, two fill-in XFA forms) and one recorded call.
These cleaned sample files are not part of this repository.
The declared form templates match only those two forms.

## Manufacturing

### Structured data

The structured data is Microsoft's AdventureWorks OLTP sample.
It is synthetic sample data. It is not real customer or supplier data.

| Item | Value |
| --- | --- |
| Source | <https://github.com/microsoft/sql-server-samples>, `samples/databases/adventure-works/oltp-install-script/` |
| Pinned commit | `8fe3fd0c9a825fef3ae6d601e97537b612d7b214` |
| Licence | MIT; a copy is `demo_data/manufacturing/LICENSE-MICROSOFT.txt` |
| Tables | 25 populated tables, 391,347 rows |
| Semantic model | `manufacturing.ossie.yaml`, 240 definitions |

The setup job downloads the pinned files with curl and checks each against its SHA-256.
A failed download or a checksum mismatch stops the build.

The projection keeps all source rows of each selected table.
It is not the full 71-table schema.
Ten foreign keys target omitted tables.
Source descriptions are Microsoft descriptions, not governed semantic definitions.

### Documents

The synthetic documents name only parties, products and orders that are rows of the sample data.

The pack manifest holds planted truth from the generator. It is not an independent gold set.

The native documents were converted to text and are not human reviewed.
Only the text conversions ship. The original files stay out of the repository.

## What not to do

- Do not link a public file to an entity.
- Do not treat planted truth in a pack manifest as an independent gold set.
- Do not replace a failed live call with sample data.
- Do not present synthetic data as real.
