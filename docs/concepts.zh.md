# 概念

任务是一个映射。
给定一个语义层，对每个非结构化段落判断它陈述了哪些定义的值，或与哪些定义相关。
也可以弃权。
然后把这些证据归并为与语义层相连的业务概念。
语义层从不被编辑。

## 语义层

语义层描述数据仓库的表。
它为每个字段和指标命名并给出定义。
它声明表如何连接。

在本系统中，每个数据集的语义层是一个 Ossie YAML 文件。
文件包含表、带描述和数据类型的字段、声明的关系和指标。
语义层是给定的，不是学习得到的。
系统读取它，从不更改它。

| 数据集 | 语义层中的定义数 |
| --- | --- |
| Financial Services（金融服务） | 143 |
| Manufacturing（制造） | 240 |

每个定义有一张文本卡、一个单位和一张表。
声明的关系是列之间的多对一链接。

## 输入

论文列出六种输入。系统不学习也不更改其中任何一种。

| 输入 | 内容 |
| --- | --- |
| 结构化数据 | 带行的表。以只读方式载入私有 PostgreSQL 的 CSV 投影。 |
| 语义模型 | Ossie 文件中的表、字段、关系和指标。 |
| 非结构化来源 | 文档、可填写表单和音频。文件由 SHA-256 固定。每个文件带一个数据标签。 |
| 访问策略 | 带角色和数据集的主体，以及对每个受限主体不可见的来源。 |
| 人工决定 | 更正、批准和拒绝，对构建或写入的确认，发布版本的发布。 |
| 问题 | 一个自然语言问题和提问的主体。 |

每个来源带一个数据标签：合成、公开，或清理后的示例文件。
公开文件的范围是 `extraction_only`。
它们会被链接到定义。
它们从不被归纳为概念，也从不与实体关联。

## 段落

段落是可读来源的一个分块。
它有文本和上下文。
上下文是标题、最近的小标题，对通话来说还有说话人。
每种文件类型如何切分，见[摄取](ingestion.md)。

## 证据链接

证据链接用语义层的术语记录一个段落所说的内容。
它包含分块、定义、关系、陈述的值、单位和期间。
它还包含该分块的实体键。

一个段落最多可有三条链接，也可以没有。
没有是一种被记录的结果，不是缺口。

### 关系

| 关系 | 含义 |
| --- | --- |
| `states_value_of` | 段落为一个可识别的实体陈述了该定义的值。 |
| `is_about` | 段落讨论该定义，但没有陈述它的值。 |
| `none` | 没有合适的定义。段落弃权。 |

关系规则很严格。
`states_value_of` 需要为一个可识别的实体给出该定义的值。
承诺、目标、指控，或不同的单位、粒度或期间，最多只能是 `is_about`。

### 规范定义

由声明的关系连接的两个字段可以持有同一个键。
规范映射从外键列追到它所引用的主键。
每条链接同时保存选中的定义和它的规范定义。

### 实体键

实体键属于分块，而不属于选中的定义。
键有三种找到的方式。

- **陈述。** 分块包含某个键列的一个已有值。
- **推导。** 一个陈述的键通过声明的关系到达另一张表。
- **继承。** 来源恰好陈述了某张表的一个键，而这个分块没有陈述任何键。

字母数字混合的标识符在任何位置都可解析。
单独的数字只有紧跟从模型推导出的标签时才可解析。
单独的名称不解析任何东西。

## 概念

概念是在证据中发现的业务想法。
每个概念通过映射谓词链接到语义层的定义。

| 来源类型 | 含义 |
| --- | --- |
| `both` | 锚定在语义层的一个结构化概念上 |
| `document` | 仅在文档中发现 |

谓词来自 SKOS：`exactMatch`、`closeMatch` 和 `relatedMatch`。
代码根据证据计数计算谓词。
模型不选择它。
见[管线 B](pipeline-b.md)。

## 语义层从不被编辑

系统不更改语义模型。
它不合并实体或客户。
没有人工确认和可见的预览，它不向任何共享表写入。

概念指向定义。它不向语义层添加字段。
发布版本包含基础模型，以及扩展块中的目录。
发布版本内的基础模型保持不变。

## 输出

| 输出 | 内容 |
| --- | --- |
| A. 证据链接 | 对每个段落，它陈述了值或与之相关的定义，或者没有 |
| B. 概念目录 | 在证据中发现并链接到定义的业务概念 |
| 回答 | 每个问题一个答复，每个数字都由 SQL 或代码计算 |

论文定义了输出 A 和 B。
工作区还把写出表行作为一项系统功能。见[表行](output-c.md)。

## 词汇表

弃权 (Abstention)
:   没有合适定义的段落不保留链接。该结果会被存储。

锚定概念 (Anchored concept)
:   语义层中的一个概念，它通过对链接的聚合收集证据，不调用模型。

候选 (Candidate)
:   支持度低于最低要求的概念或概念链接。它被存储并显示，但不导出。

规范定义 (Canonical definition)
:   外键定义通过声明的关系解析到的主键定义。

定义卡 (Definition card)
:   用于检索的一个定义的文本：标签、同义词、描述。

降级 (Degraded)
:   模型答复中没有有效项的分块。

证据链接 (Evidence link)
:   一条记录（分块、定义、关系、值、单位、期间），带实体键。

误链接率 (False-link rate)
:   没有合适定义却仍获得链接的段落所占的比例。

防护规则 (Guard)
:   在模型决策之后应用的确定性规则。

发布版本 (Release)
:   已批准目录和映射更正的带版本 Ossie 导出。

残余 (Residual)
:   链接中没有陈述值的段落。只有这些段落会进入归纳模型。

检索接近度 (Retrieval proximity)
:   一个定义对一个段落的关键词与嵌入组合得分。它不是置信度。

受限读者 (Restricted reader)
:   部分来源对其不可见的账户。

不可见来源 (Withheld source)
:   主体不得读取的来源。对该主体，它从不被读取、引用或摘要。
